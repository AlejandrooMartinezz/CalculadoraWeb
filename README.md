# 🧮 Calculadora Web Vanilla

Una calculadora web interactiva y responsiva desarrollada para la asignatura de **Desarrollo de Interfaces**. Construida desde cero con tecnologías web estándares (HTML5, CSS3 y JavaScript vanilla), sin librerías ni frameworks externos.

## ✨ Características

* **Operaciones básicas:** Suma, resta, multiplicación y división.
* **Gestión de pantalla:** Limpieza completa (`C` / `AC`), borrado del último caracter e ingreso de decimales.
* **Interfaz intuitiva:** Diseño adaptativo con Flexbox / CSS Grid compatible con ordenadores y dispositivos móviles.
* **Feedback visual:** Animaciones y estados `:hover` / `:active` en los botones para mejorar la experiencia de usuario.
* **Control de errores:** Manejo de divisiones por cero y desbordamiento de pantalla.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica de la pantalla y la botonera.
* **CSS3:** Maquetación, paleta de colores, diseño responsivo y efectos visuales.
* **JavaScript (ES6+):** Lógica matemática, manipulación del DOM y gestión de eventos.

## 🚀 Cómo Ejecutar el Proyecto
No requiere instalación de dependencias ni procesos de compilación.
1. Clona el repositorio:
git clone [https://github.com/tu-usuario/tu-repositorio.git](https://github.com/tu-usuario/tu-repositorio.git)
2. Accede a la carperta del proyecto.
cd tu-repositorio
3. Abre la aplicación:
Abre el archivo main.html en tu navegador o ejecútalo mediante la extensión Live Server de VS Code.
